# OTP Logger – WordPress Plugin

A clean and modular WordPress plugin for logging API interactions with a customizable API endpoint.

## 🔧 Features

- Admin settings page with editable API URL
- Clickable button to trigger API requests
- Log table with:
  - Request date
  - Response content
  - OTP code
- Searchable and sortable log table (DataTables)
- Export logs to Excel and CSV with customizable file names
- Fully translatable (English & Persian)
- Admin-only script and style loading

## 🌐 API Used
Default API: `https://acavent.porozhechi.ir/api/send-otp`  
(Can be updated via plugin settings)

## 📁 Installation

1. Download or clone this repository.
2. Upload the plugin folder to `wp-content/plugins/`.
3. Activate the plugin from the WordPress admin panel.
